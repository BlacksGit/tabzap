# TabZap - Close Duplicate Tabs

One click closes duplicate tabs in the current window and keeps the first of each. The badge shows how many were closed.

- Ignores pinned tabs and browser internal pages
- URLs that differ only by `#fragment` count as the same page
- Only permission: `tabs`

## Install

Download `tabzap.zip` from the [latest release](https://github.com/BlacksGit/tabzap/releases/latest).

- **Chrome / Brave / Edge:** unzip, open `chrome://extensions`, turn on Developer mode, click "Load unpacked" and pick the folder.
- **Firefox:** open `about:debugging#/runtime/this-firefox`, click "Load Temporary Add-on" and pick `manifest.json` from the unzipped folder.

## Privacy

No data is collected, stored remotely or sent anywhere. No analytics, no network requests.
